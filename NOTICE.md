# Notice and Limitations

This public evaluation slice is a synthetic technical artifact for standards discussion, interoperability review, and running-code demonstration. It is not live payment infrastructure, production authorization infrastructure, or a compliance certification.

Do not use this package to process real payments, store payment-card data, call live processors, modify production checkout, operate a production authorization boundary, or make production security claims. Production deployment would require independent security review, compliance review, operational hardening, key-management design, status/revocation service design, threat modeling, and separately approved distribution terms.

No standards-body endorsement is implied by this artifact. This artifact is not an IETF standard, not an official reference implementation, not a certification program, not a certificate registry, and not a production non-bypassability claim. The included code and examples are intended to make the technical discussion reproducible.
